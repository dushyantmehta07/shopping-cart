# shopping-cart
# 🛒 Shopping Cart Interface

This is a simple and responsive shopping cart interface built using **HTML**, **CSS**, and **JavaScript**. It allows users to add items to the cart, view them, update quantities, and see the total price in real-time.

---

## 🔧 Technologies Used

- **HTML5** – for structure  
- **CSS3** – for styling and layout  
- **JavaScript (Vanilla)** – for cart logic and interactivity  

---

## ✨ Features

- Add items to cart  
- Remove items from cart  
- Update item quantity  
- Calculate total price dynamically  
- Responsive design for mobile & desktop  

---


## 🚀 How to Run

1. **Download or clone** this repository  
2. Open `index.html` in your browser  
3. Start adding items to the cart and interact with the UI
